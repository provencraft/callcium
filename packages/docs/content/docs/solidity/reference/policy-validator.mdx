## Functions

### validate

Validates policy data for semantic issues.

Reverts when the descriptor is not well-formed; semantic validation is defined
only over a well-formed descriptor.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyValidator.sol#L110)

```solidity
function validate(PolicyData memory data) internal pure returns (Issue[] memory);
```

**Parameters**

| Name   | Type         | Description                  |
| ------ | ------------ | ---------------------------- |
| `data` | `PolicyData` | The policy data to validate. |

**Returns**

| Name     | Type      | Description                  |
| -------- | --------- | ---------------------------- |
| `<none>` | `Issue[]` | All validation issues found. |
