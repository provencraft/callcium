---
title: "Path"
description: "Encodes and inspects descriptor paths as big-endian uint16 sequences."
---

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/Path.sol#L11)

Paths represent navigation through ABI-encoded calldata:

- path\[0] is the top-level argument index.
- path\[1..n] are indices into nested composites (tuples, arrays).

## Constants

### ALL

Universal quantifier for array paths (∀). Rule must pass for every element.

Only valid immediately after an array node. Empty arrays give true (vacuous truth).

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/Path.sol#L14)

```solidity
uint16 internal constant ALL = 0xFFFF;
```

### ANY

Existential quantifier for array paths (∃). Rule must pass for some element.

Only valid immediately after an array node. Empty arrays give false.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/Path.sol#L18)

```solidity
uint16 internal constant ANY = 0xFFFE;
```

| Name        | Type      | Description             |
| ----------- | --------- | ----------------------- |
| `self`      | `bytes`   | The encoded path bytes. |

**Returns**

| Name     | Type     | Description                               |
| -------- | -------- | ----------------------------------------- |
| `<none>` | `uint16` | The uint16 step value at the given index. |
