### add

Adds a constraint to the active group with validation. A path through `Path.ALL` or `Path.ANY` adds
its operators to the body of the group's loop over that array with that quantifier.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L88)

```solidity
function add(PolicyDraft memory draft, Constraint memory constraint) internal pure returns (PolicyDraft memory);
```

**Parameters**

| Name         | Type          | Description            |
| ------------ | ------------- | ---------------------- |
| `draft`      | `PolicyDraft` | The draft state.       |
| `constraint` | `Constraint`  | The constraint to add. |

**Returns**

| Name     | Type          | Description                                                   |
| -------- | ------------- | ------------------------------------------------------------- |
| `<none>` | `PolicyDraft` | The updated draft state with the constraint's rules appended. |

### build

Builds the final policy blob with strict validation.

Reverts with the storage validation error of a blob that fails it, and with every validation issue when
there is any.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L123)

```solidity
function build(PolicyDraft memory draft) internal pure returns (bytes memory policy);
```

**Parameters**

| Name    | Type          | Description                    |
| ------- | ------------- | ------------------------------ |
| `draft` | `PolicyDraft` | The draft state to build from. |

**Returns**

| Name     | Type    | Description              |
| -------- | ------- | ------------------------ |
| `policy` | `bytes` | The encoded policy blob. |

### buildUnsafe

Builds the final policy blob without validation.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L133)

**Returns**

| Name     | Type    | Description              |

## Errors

### NoConstraintOperators

Thrown when the constraint has no operators.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L35)

```solidity
error NoConstraintOperators();
```

### InvalidContextPath

Thrown when a context-scope path does not have exactly one step.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L39)

```solidity
error InvalidContextPath(uint256 depth);
```

**Parameters**

| Name    | Type      | Description     |
| ------- | --------- | --------------- |
| `depth` | `uint256` | The path depth. |

### UnknownPathStep

Thrown when a path step lies in the reserved marker range and is neither `Path.ALL` nor `Path.ANY`.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L44)

```solidity
error UnknownPathStep(bytes path, uint256 stepIndex);
```

**Parameters**

| Name        | Type      | Description                   |
| ----------- | --------- | ----------------------------- |
| `path`      | `bytes`   | The encoded be16 path.        |
| `stepIndex` | `uint256` | The step index of the marker. |

### InvalidNestedLoop

Thrown when a path contains more than one quantifier step.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L49)

```solidity
error InvalidNestedLoop(bytes path, uint256 stepIndex);
```

**Parameters**

| Name        | Type      | Description                              |
| ----------- | --------- | ---------------------------------------- |
| `path`      | `bytes`   | The encoded be16 path.                   |
| `stepIndex` | `uint256` | The step index of the second quantifier. |

### SetTooLarge

Thrown when a set contains more members than the data length can represent at its operand type's width.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/contracts/src/PolicyBuilder.sol#L52)

```solidity
error SetTooLarge();
```
