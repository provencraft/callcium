## Functions

### lookupOp

Map an operator code to its display label. Strips the NOT flag automatically. A context source adds ` ctx`.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/constants.ts#L364)

```ts
function lookupOp(code: number): OpInfo;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `code` | `number` | Operator byte value (can include the NOT flag). |

**Returns**

`OpInfo` — Display metadata for the base operator.

### lookupTypeCode

Map a raw type code byte to its ABI type label, structural category, and dynamism.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/operators.ts#L267)

```ts
function lookupTypeCode(code: number): TypeCodeInfo;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `code` | `number` | A single-byte descriptor type code. |

**Returns**

`TypeCodeInfo` — Label, type class, and whether the code alone implies ABI dynamism (false for tuples and static arrays).

## Types

### Op

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/constants.ts#L311)

### Source

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/constants.ts#L322)

### TypeCode

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/constants.ts#L129)

### Scope

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/constants.ts#L215)
