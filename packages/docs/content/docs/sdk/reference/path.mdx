## Functions

### parsePathSteps

Parse a BE16-encoded hex path into an array of step values.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/path.ts#L45)

```ts
function parsePathSteps(path: `0x${string}`): number[];
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `path` | `` `0x${string}` `` | 0x-prefixed hex string containing BE16-encoded path steps. |

**Returns**

`number[]` — Array of numeric step values.
