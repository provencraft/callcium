## PolicyBuilder

Fluent API for drafting policies from constraints.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L133)

### Methods

### create

Create a builder from a function signature.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L146)

```ts
function create(signature: string): PolicyBuilder;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `signature` | `string` | The function signature (for example "transfer(address,uint256)"). |

**Returns**

`PolicyBuilder` — A new builder.

### createRaw

Create a selectorless builder from a comma-separated type list.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L158)

```ts
function createRaw(typesCsv: string): PolicyBuilder;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `typesCsv` | `string` | The comma-separated ABI types (for example "uint256,address"). |

**Returns**

`PolicyBuilder` — A new builder.

### add

Add a constraint to the active group. A path through `Quantifier.ALL` or `Quantifier.ANY` adds its operators to the
body of the group's loop over that array with that quantifier.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L171)

```ts
function add(constraint: Constraint): this;
```

**Parameters**

| Name | Type | Description |
| --- | --- | --- |
| `constraint` | `Constraint` | The constraint to add. |

**Returns**

`this` — This builder.

### or

Start a new constraint group (OR semantics between groups).

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L199)

```ts
function or(): this;
```

**Returns**

`this` — This builder.
