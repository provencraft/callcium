### build

Build the policy into an encoded binary blob with strict validation.
Throws on any issue, regardless of severity. Use validate to
inspect issues, or buildUnsafe to encode without validation.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L263)

```ts
function build(): `0x${string}`;
```

**Returns**

`` `0x${string}` `` — The policy as a 0x-prefixed hex string.

### buildUnsafe

Build the policy into an encoded binary blob without validation.
The resulting policy may be invalid. Prefer build; use this
only to knowingly bypass a reported issue.

[Git Source](https://github.com/provencraft/callcium/blob/main/packages/sdk/src/policy-builder.ts#L280)

```ts
function buildUnsafe(): `0x${string}`;
```

**Returns**

`` `0x${string}` `` — The policy as a 0x-prefixed hex string.
